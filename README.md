# landfill-sensitivity-sample
Minimal MATLAB implementation of sensitivity analysis for landfill liner insulation parameters.
#Sensitivity Analysis - Landfill Liner Study (Minimal Repository)

This repository contains a **minimal MATLAB script** demonstrating Morris screening sensitivity analysis on landfill liner insulation parameters (ETs, Material, Moisture, Thickness).

Other scripts will be available upon request

No custom code was developed; this script uses standard MATLAB functions to illustrate the workflow.

---

## Contents

- `sensitivity_analysis_sample_code.m` – Main script implementing the Morris method with the supplementary data inside

---

## Usage

1. Download or clone this repository
2. Open `sensitivity_analysis_sample_code.txt` 
3. Copy the code in MATLAB (desktop or online)
4. Run the script to reproduce the Morris sensitivity plot
